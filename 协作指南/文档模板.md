# 轻量文档模板

按需复制相关小节到已有主版或真实模块目录，不创建六份空文件。维护要求见[文档维护约定](文档维护约定.md)，已有R1.1卡片可继续沿用原格式和编号。

## 文档头与模块入口

```markdown
# 明确的业务主题

> 状态：草案 / 待确认 / 已确认 / 已废弃
> 版本与日期：填写实际值
> 适用范围：当前一期 / 未来预留 / 待确认
> 维护角色与人员：未指定时如实记录
> 来源和关联：填写主版、编号与可访问链接

说明本模块负责什么、服务谁，与上下游如何协作。

| 阅读步骤 | 主版与具体编号 |
|---|---|
| 产品需求 | 对应FR和场景 |
| 业务规则 | 对应BR，不复制共用算法 |
| 领域设计 | 相关模型与职责、接口、事务章节 |
| 实施任务 | 对应TASK及依赖，前后端分工 |
| 验收用例 | 对应UAT，正常/异常/边界覆盖 |
| 决策记录 | 对应PD及采纳状态 |

列出本次不做的范围、待确认事项和完成证据。
```

## 需求、规则与设计

| 类型 | 可复用内容骨架 |
|---|---|
| PRD | FR编号、背景/目标、用户和场景、主流程、功能范围与排除项、分期、交互及验收目标、来源 |
| 规则 | BR编号、来源/PD、适用范围和版本、前置、正常状态/数量/金额变化、异常/边界、重复与并发、撤销/更正、正反算例 |
| 设计 | 关联FR/BR、业务概念与实体关系、模块职责/权威事实、接口及字段约束、权限/事务/幂等、兼容与退出、待决项 |

## 实施任务

```markdown
### 任务编号与明确交付

| 项目 | 内容 |
|---|---|
| 关联 | FR、BR、PD、UAT及规范提交 |
| 依赖和开工门槛 | 必须先完成的任务、规则版本、环境或批准条件 |
| 后端交付 | 正式事实、命令/查询、契约、迁移与旧链退出范围 |
| 前端交付 | 应用/domain/页面、生成Client、权限与错误恢复 |
| 不做范围 | 本切片明确排除项 |
| 完成标准 | 可重复执行的验证及预期，不写“基本可用” |
| 结果与证据 | 实际代码提交/拉取请求、接口版本、环境、命令和结果 |
| 状态及剩余事项 | 实现、验收、商业启用分别写；未执行如实记录 |
```

## 验收用例与执行记录

```markdown
### 用例编号与验证目标

- 关联：FR、BR、TASK、规则版本。
- 类型：正常 / 异常 / 边界；一期功能 / 结构检查 / 后续算例。
- 前置与初始数据：环境、权限、合成数据、依赖状态。
- 步骤：按可重现顺序描述输入和动作。
- 预期：页面结果、服务端状态/事实、数量/金额及副作用。
- 执行：未执行；执行后填写日期、环境、操作者、实际结果、证据和缺陷。
```

## 决策与问题

```markdown
### 决策编号与主题

- 状态：待确认 / 已确认 / 已废弃。
- 背景和来源：冲突原文、事实或当前约束。
- 可选方案与影响：至少说明本次重要取舍和放弃理由。
- 建议或已采纳结论：明确区分推荐与授权。
- 采纳记录：人及权限、日期、范围/版本；无证据时填待确认。
- 影响：FR/BR/设计/TASK/UAT、在途与已结算事实、迁移/回滚限制。
- 替代关系：被替代记录、新记录及生效边界。
```

未确认问题进入[问题清单](../维护记录/待确认事项.md)：描述、来源、影响编号、所需决定、阻断范围、建议责任角色、状态/关闭证据。关闭时回写主版及采纳记录，不只在问题清单回复一句“已解决”。
