# 盘点与查找

> 范围：一期五类入口；规则待按任务采纳，业务任务未执行。返回[租洗总览](../README.md)。

涵盖疑失查找、指定客户盘点、点数、厂内呆滞和净仓盘点。扫描观察、差异确认和调账分开，普通点数不改库存，盘亏不自动产生客户赔偿。

| 阅读步骤 | 主版入口 |
|---|---|
| 产品需求 | [FR-R012](../共用规范/产品需求.md#PRODUCT-REQUIREMENTS) |
| 业务规则 | [BR-R022 盘点与调整](../共用规范/业务规则.md#BR-R022)、[BR-R028 重扫与迟到](../共用规范/业务规则.md#BR-R028) |
| 领域设计 | [盘点会话与差异事实](../共用规范/领域与技术设计.md#MODEL-FACTS)、[版本与并发](../共用规范/领域与技术设计.md#MODEL-TRANSACTIONS) |
| 实施任务 | [TASK-16 五类入口](../共用规范/实施计划.md#TASK-16)、[TASK-18 页面](../共用规范/实施计划.md#TASK-18) |
| 验收用例 | [UAT-R047 期间移动](../共用规范/验收用例.md#UAT-R047)、[UAT-R048 零扫描](../共用规范/验收用例.md#UAT-R048)、[UAT-R049 旧代消息](../共用规范/验收用例.md#UAT-R049)、[UAT-R050 点数不调账](../共用规范/验收用例.md#UAT-R050) |
| 决策记录 | [PD-029、PD-031](../共用规范/决策记录.md#DECISION-REGISTER) |

后端提供小范围快照、移动版本复核及独立调整记录；前端区分继续扫描、重扫、确认零结果、差异复核和确认调整。依赖 TASK-04/05；与[资产与库存](../资产与库存/README.md)核对期间合法移动。

完成须覆盖全空盘点、旧代消息及扫描期间移库。责任处置另转[异常处理与赔偿](../异常处理与赔偿/README.md)，相关授权见[待确认事项](../../../维护记录/待确认事项.md)。
