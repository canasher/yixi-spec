# 设备接入

> 范围：一期实际选定设备；协议、固件和样机待核实，业务及真机验收未执行。返回[租洗总览](../README.md)。

负责扫描上行、连接、稳定事件标识、增量同步、离线恢复与受控更新。传输接收与业务生效分开；有人操作身份和无人设备主体分别接入。
