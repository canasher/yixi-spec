# 客户资金

> 范围：一期内部资金子账；真实资金操作有商业启用门槛。业务任务未执行。返回[租洗总览](../README.md)。

负责线下凭证充值审核、现金/赠送/信用维度、支付与还款分摊、退款权益和在退占用。资金账户不与 IAM Account 混用，也不默认接入外部在线支付。

后端维护批准退款来源、双限额、在退记录、原债及还款来源；前端分开显示现金、赠送、授信和退款去向，并在未知结果时查原操作。依赖 TASK-02/03/11，订单和赔偿模块只能通过正式资金契约协作。

验收必须包含连续退款、并发争用、结果未知、部分/全部信用已偿和赠送不兑现。商业参数未采纳可做隔离模拟，不能真实入账；[待确认事项](../../../维护记录/待确认事项.md)记录所需授权，现有算例不代表授权。
