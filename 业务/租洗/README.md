## 整体业务

服务客户是洗涤厂及其酒店客户；厂内运营、仓管、生产、司机、财务和酒店人员通过不同端完成各自职责。先配置客户、服务、品项、价格和配额，再登记资产及有凭证的期初；订单、实物履约、回收、处理、费用和资金各有独立事实，不能用一个单据状态代替全部结果。

```text
客户与服务 ──→ 资产与库存 ──→ 生产与打扎 ──→ 订单与配送 ──→ 酒店持有
                   ↑                                    │
                   └──────── 收货与日单 ←────────────────┘
盘点与查找 / 异常处理与赔偿 ──→ 受控更正、处置与费用
报价与结算 ←── 费用来源 ──→ 客户资金
酒店查询与报表读取上述事实；设备接入、作业配置与运维支撑各作业环节。
```

这张图用于阅读定位，实际事务和依赖以规则及任务卡为准。首单可从有证据的期初净品开始；正常收脏不重新打开已完成订单。

原清单 123 组功能保留：一期 76、二期 38、三期 9。四端一期分别为工厂 PC 36、生产终端 7、物流终端 18、酒店 H5 15。分组数量不是页面数、表数或完成率。[产品需求](共用规范/产品需求.md)保留逐项菜单，[范围追踪](结构化数据/范围追踪.json)保留单元格、动作及编号关系。

## 怎样开始实施

先按[TASK-00](共用规范/实施计划.md#TASK-00)固定当前两仓基线及旧业务退出清单，再按[TASK-01](共用规范/实施计划.md#TASK-01)采纳本次切片的范围/规则。首批进入客户与服务、配额底座，再到资产期初；实际依赖顺序见[实施计划](共用规范/实施计划.md)。

每个模块任务与[TASK-18](共用规范/实施计划.md#TASK-18)联合交付前端，按正式契约接入；不能以全局页面任务代替业务任务。最后由[TASK-21](共用规范/实施计划.md#TASK-21)核对一期覆盖、旧测试链退出、故障恢复及环境验收。未确认事项只阻断对应依赖，不要求提前批准全部二三期需求。
