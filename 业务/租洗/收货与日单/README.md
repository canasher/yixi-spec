# 收货与日单

> 范围：一期；规则采纳状态见对应 PD，业务任务未执行。返回[租洗总览](../README.md)。

串联司机收脏、工厂复核、工作台补漏和业务日汇总。原始扫描、有效回收和日单汇总分层；日单不能再次入库，复核不能重复释放配额。
