# 异常处理与赔偿

> 范围：一期；真实赔偿/回购有商业启用门槛。规则待按任务采纳，业务任务未执行。返回[租洗总览](../README.md)。

管理返洗、特洗、重污破损、报废、疑失丢失和找回。实物状态、客户责任、费用调整与资金退款各自记录；不能因找回或报废就自行决定金额或产权。
